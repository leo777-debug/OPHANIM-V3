# Presentation Basemap

Country geometry: Natural Earth, 1:110m Admin 0 countries (177 features).
Source file:
https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_110m_admin_0_countries.geojson

Natural Earth states its raster and vector map data are in the public domain:
https://www.naturalearthdata.com/about/

Properties were reduced to country name and ISO code. Geometries were not
changed. On-map attribution identifies Natural Earth when this fallback is used.

`globe-poster.png` is an actual MapLibre render of this same bundled geography and
Ophanim style, generated by `npm run presentation:poster`. It contains no vessels,
aircraft, incidents or live claims. It is the explicitly labelled starter view
while the interactive map initializes, not a replay of feed observations.

The interactive map uses Ophanim's original atlas renderer. Its night style is
OpenFreeMap Dark: https://tiles.openfreemap.org/styles/dark
Documentation: https://openfreemap.org/quick_start/
Style provenance: https://github.com/hyperknot/openfreemap-styles
Credit: OpenFreeMap, OpenMapTiles, OpenStreetMap contributors (ODbL).

The bundled Natural Earth night palette is an overview fallback when the remote
style cannot be loaded. Fonts for the renderer's existing text labels use
OpenFreeMap's glyph service. Offline geography and icon silhouettes do not need
those glyph downloads; street details and external labels need internet.

The original optional Earth and satellite overlays use these Esri endpoints:
https://server.arcgisonline.com/ArcGIS/rest/services/World_Topo_Map/MapServer/tile/{z}/{y}/{x}
https://server.arcgisonline.com/ArcGIS/rest/services/World_Imagery/MapServer/tile/{z}/{y}/{x}
Credit: Esri and the respective data contributors. Attribution reference:
https://www.esri.com/en-us/legal/terms/data-attributions

No CARTO API key is needed in presentation mode. Normal atlas defaults are
unchanged when presentation mode is OFF.
